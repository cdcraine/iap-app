# IAP App

## Concept Brief

The Student Task Manager is an application designed to help college students organize and manage their academic responsibilities in one place. The application will allow users to create, view, update, and complete tasks such as assignments, projects, exams, and other academic deadlines. The goal is to provide students with a simple way to keep track of their responsibilities and improve organization throughout the semester.

## Tech Stack

- **Package Manager:** pip
- **Testing Framework:** pytest
- **Version Control:** Git
